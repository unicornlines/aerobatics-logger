# Aerobatics Flight Logger

An onboard flight data logger and an Apple debrief app (iOS, iPadOS, macOS) for aerobatics training.

The specification lives in the project's spec document. This repository holds:

- `hardware/`: the KiCad schematic and PCB
- `firmware/`: the STM32H723 on-board firmware (planned)
- `app/`: the SwiftUI debrief app (planned)
